# Mobile Application
This mobile application is a simple app that takes name of a country from the user and provides poverty information, and details of available non-profit organisations.
The aim is to help people make informed decision about donations, ultimately trying to solve the SDG Goal 1: No Poverty.

# SDG_App folder contains the Android Studio code for the final app.

# no-poverty-1.0.apk is the installation file for the app.
